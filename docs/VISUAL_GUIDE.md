# 🎨 비주얼 가이드 — 키즈짱 시장놀이

> 모든 UI·이미지의 **통일성 기준**. 새 아트는 이 규격을 그대로 따릅니다.
> (수치·색은 현재 `css/style.css`와 `js/ui/sprites.js`에서 실제 사용 중인 값입니다.)

## 1. 아트 디렉션
- **컨셉**: 둥글둥글·말랑한 스토리북 카툰. 2D 탑다운(위에서 비스듬히 내려다보는) 마을 생활 게임.
- **톤**: 밝고 따뜻한 파스텔, 아동 친화적, 귀엽고 명확. 원작 「키즈짱 시장놀이」의 아기자기함.
- **핵심 3원칙**
  1. **평면(flat) + 최소 음영**: 큰 색면 위주, 그라데이션은 은은하게만.
  2. **굵고 둥근 실루엣**: 작은 크기에서도 한눈에 알아보게. 얇은 디테일 지양.
  3. **일관된 광원·그림자**: 광원은 위쪽, 모든 오브젝트는 발밑에 타원 그림자.

## 3. 캔버스·사이즈 그리드
- **월드 캔버스**: 내부 해상도 `600 × 440` (CSS로 폭 100% 스케일).
- **스프라이트 소스**: 모두 `viewBox="0 0 64 64"` SVG. 발밑 그림자 `<ellipse cx="32" cy="58" rx="15" ry="4" fill="rgba(0,0,0,.16)"/>`.
- **캔버스 렌더 크기**(drawImage): 자원/오브젝트 **76px**, 건물 **84px**, 캐릭터 **52px**. (게임 코드가 이 크기로 배치)
- **UI 아이콘**(HUD/인라인 svg): `viewBox="0 0 24 24"`, 표시 22px.
- 피벗: 캐릭터/오브젝트는 **발끝(바닥) 기준**으로 놓임(중심 아래쪽에 무게).

## 4. 캐릭터 리그 (플레이어)
64×64 좌표계 기준 표준 비율 — 새 프레임/캐릭터도 동일 비율 유지.
- **머리**: 원 `cx32 cy23 r12` (피부). 얼굴 눈 `r1.7` (`#3a2b1f`), 입 곡선.
- **모자**: 타원 `cx32 cy15 rx13 ry6` + 챙 곡선.
- **몸통**: 둥근 사각 `x23 y33 w18 h18`, r7~8.
- **팔**: 좌우 `w6 h12` 피부색.
- **다리(바지)**: `w5`, y49~59, 프레임마다 길이/위치 교차.
- **방향**: `down`(정면) / `up`(뒷면: 뒤통수+가방) / `left`(옆모습). **`right`는 `left`를 좌우반전**해서 사용(코드가 처리) — 별도 제작 X.
- **걷기 애니메이션(2프레임)**: `_0`/`_1`. 다리 위치를 교차(정면/뒷면=상하 길이 교차, 옆모습=보폭 벌림↔모음). 이동 중 6프레임마다 교대.
- **채집 애니메이션(2프레임)**: `char_work_0`(도구 위로) / `char_work_1`(도구 아래로 내려찍기). 정면 기준.
- 스프라이트 키 규칙: `char_<dir>_<frame>` (dir: down/up/left, frame: 0/1), `char_work_0/1`.

## 5. 월드 오브젝트 규격
각 오브젝트는 64×64, 발밑 그림자 포함, 76px(건물 84px)로 렌더.
| 종류 | 키(예) | 요소 |
|---|---|---|
| 나무/채집터 | `tree` | 갈색 기둥 + 3~4겹 잎사귀 원 |
| 낚시터 | `fishspot` | 물 타원 + 물고기 + 물결 |
| 광맥 | `ore` | 각진 바위 + 보석 결정 |
| 곡식/사냥터 | `wheat` | 밀 줄기 다발(금색) |
| 고물 | `trash` | 쓰레기통 + 뚜껑 |
| 해적선 | `pirate` | 나무 선체 + 돛 + 해골기 |
| 던전 입구 | `cave` | 바위 아치 + 어두운 입구 |
| 하늘나라 | `cloud` | 구름 + 후광 + 천사얼굴 |
| 건물(상점/집/기부소/수첩) | `b_shop`/`b_home`/`b_donate`/`b_journal` | 지붕+벽+문/창, 상징(차양/하트/책) |
| 표지판 | (캔버스에 그림) | 나무 기둥 + 크림색 판 + 화살표+지명 |

## 6. UI 컴포넌트 규격 (`css/style.css` 기준)
- **게임기 프레임(.device)**: `border:5px solid bezel; border-radius:26px`, device 그라데이션.
- **HUD 칩(.chip)**: cream 배경, `border-radius:11px`, 그림자 `0 2px 0 rgba(0,0,0,.12)`, 아이콘 22px + 라벨/값.
- **버튼(.btn)**: `border-radius:14px`, 하단 그림자 `0 5px 0 rgba(0,0,0,.18)`, 눌리면 4px 내려감. 색은 역할별 토큰.
- **액션바(.abtn)**: cream, 아이콘(이모지→SVG로 교체 대상) + 라벨, 배지.
- **팝업(.popcard)/모달(.modal)**: 흰 테두리 3px, 큰 라운드(20~22px), 팝인 스케일 애니메이션.
- **바(.bar)**: 높이 8~10px, 라운드, 내부 채움 그라데이션(gong=gold, fatigue=green→gold→red).
- **채집 게이지**: 캐릭터 위 초록 채움 바 + ✨.
- **HUD 아이콘 5종**(현재 인라인 SVG): 계급(메달), 별머니(별), 체력(하트), 피로(zZ), 선행(선물). → 통일된 라인/색으로 리파인 대상.
- **액션 아이콘 4종**: 가방/빠른이동/설명서/설정. (현재 이모지 → SVG 아이콘화 대상)

## 7. 명명·포맷·연결 규칙
- **포맷**: SVG만. 월드는 `js/ui/sprites.js`의 `SVGS[key]`에 문자열로. UI는 인라인 `<svg>`/CSS.
- **키 명명**: 소문자 스네이크. 캐릭터 `char_<dir>_<frame>`, 오브젝트=장소/대상 id(`tree`,`ore`,`b_shop`…), 몬스터 `mon_<id>`(신규 시), 아이템 `item_<id>`(신규 시).
- **부품 재사용**: 공통 조각(그림자, 머리, 몸통)은 `sprites.js` 상단 `const`로 정의해 조합(현재 방식 유지).
- **렌더 크기 고정**: 게임 코드가 76/84/52px로 그림 → SVG는 64 뷰박스 안에 꽉 차되 여백 균형 유지.

## 8. 통일성 체크(Do/Don't)
- ✅ 광원 위쪽, 발밑 타원 그림자, 굵은 실루엣, 파스텔 팔레트, 둥근 코너.
- ✅ 새 아트를 기존 것 옆에 나란히 두고 위화감 없는지 확인.
- ❌ 외곽선 두께 제각각, 사실적 음영/그라데이션 남발, 팔레트 밖 색, 얇고 복잡한 디테일.
- ❌ 오브젝트마다 다른 그림자/코너 스타일.
