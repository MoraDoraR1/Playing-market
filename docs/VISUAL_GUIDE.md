# 🎨 비주얼 가이드 (이미지 생성 규격) — 키즈짱 시장놀이

> **목적**: 이미지 생성 AI로 만드는 모든 아트가 **한 세트처럼 통일**되게 하는 규격서.
> 아트는 **고품질 래스터(PNG)** 로 생성한다. (코드용 SVG는 저품질이라 사용하지 않음 — 임시 플레이스홀더일 뿐.)
> 규격을 벗어난 결과물은 재생성한다. 실제 배치 목록은 `docs/ASSET_CHECKLIST.md` 참고.

---

## 1. 아트 디렉션
- **장르/시점**: 2D 탑다운(3/4 부감) 마을 생활 게임. 원작 「키즈짱 시장놀이」의 아기자기함.
- **스타일**: 둥글둥글·말랑한 **스토리북 카툰**. 부드러운 셀 셰이딩, 굵고 명확한 실루엣, 깨끗한 벡터풍 렌더(픽셀아트 아님, 사실적 3D 아님).
- **정서**: 밝고 따뜻한 파스텔, 아동 친화적, 귀엽고 사랑스러움.
- **핵심 3원칙**
  1. **명확한 실루엣** — 작은 크기(50~90px 표시)에서도 한눈에 식별.
  2. **부드러운 볼륨감** — 평면이되 은은한 그라데이션/하이라이트로 통통한 입체.
  3. **일관된 광원·바닥 그림자** — 광원은 위쪽, 바닥에 부드러운 타원 그림자.

## 2. 🔒 마스터 스타일 (모든 프롬프트에 공통으로 붙일 것)
> 통일성의 핵심. 아래 문장을 **모든 에셋 생성 프롬프트 끝에 그대로** 붙인다.

```
cute rounded storybook cartoon, soft cel-shading, thick clean silhouette,
warm pastel palette, gentle top-down 3/4 view, soft top lighting,
smooth vector-like finish, kids mobile game asset, high detail,
centered, isolated on transparent background, no text, no watermark, no border
```
- **네거티브(피할 것)**: `pixel art, photorealistic, 3d render, harsh shadows, gritty, dark, realistic proportions, text, letters, watermark, drop shadow box, frame, multiple objects`
- **일관 장치**: 전 에셋을 **같은 스타일 문구 + 같은 팔레트**로, 가능하면 한 배치/시드 계열로 생성.

## 3. 팔레트 (이 색 계열로 통일)
말로도 통일하되, 아래 HEX를 기준색으로 삼는다.
| 이름 | HEX | 쓰임 |
|---|---|---|
| 잔디/자연 | `#9fe08f` `#63d885` | 배경·식물 |
| 물 | `#57b7ea` `#7cccf2` | 바다·강 |
| 길/나무 | `#d8c48c` `#a0642e` `#8a5a34` | 길·목재 |
| 피부 | `#ffdcae` `#e6b98a` | 캐릭터 |
| 셔츠/바지 | `#4a90d9` `#37639a` | 주인공 의상 |
| 모자 | `#e0a95e` `#c98a4a` | 밀짚모자 |
| 금색(별머니/보상) | `#f7b731` `#ffcf33` | 강조 |
| 빨강/초록/파랑 | `#eb3b5a` `#20bf6b` `#3867d6` | UI 역할색 |
| 크림/프레임 | `#fffdf5` `#ffd98a` `#5a3e28` | UI 배경/게임기 |
- 채도는 파스텔~중간. 원색 과다·탁한 색 지양.

## 4. 해상도·포맷·배경 (필수 규격)
| 카테고리 | 생성 해상도 | 배경 | 표시 크기(참고) |
|---|---|---|---|
| 캐릭터(프레임별) | **512×512** | 투명 | ~52px |
| 몬스터/보스 | **512×512** | 투명 | ~64px |
| 자원/아이템/전리품 | **512×512** | 투명 | ~24–40px |
| 월드 오브젝트/건물 | **512×512** | 투명 | 76–84px |
| UI 아이콘(HUD/버튼) | **256×256** | 투명 | 22–28px |
| 맵 배경/타일(선택) | **1200×880** (월드 2×) | 불투명 | 전체 화면 |
- 포맷: **PNG-32(투명 알파)**. 아이콘/캐릭터/오브젝트는 반드시 배경 투명.
- 피사체는 프레임 중앙, 가장자리 여백 8~12% 확보(잘림 방지). 발밑 그림자는 피사체에 포함(투명 위 반투명 타원).
- 색공간 sRGB. 과도한 그림자/글로우 금지.

## 5. 캐릭터 규격 (주인공)
- **비율**: 2~2.5등신 치비. 큰 머리, 둥근 몸, 짧은 팔다리. 밀짚모자 소년(현재 컨셉 유지).
- **의상**: 파란 셔츠 + 남색 바지 + 밀짚모자(색은 §3).
- **방향 4종**: 정면(down)·뒷면(up, 뒤통수+작은 가방)·좌(left). **우(right)는 좌를 좌우반전**하므로 **생성하지 않음**.
- **걷기 애니메이션**: 방향마다 **2프레임**(다리 교차: 왼발↔오른발 스텝). 파일 `_0`, `_1`.
- **채집 애니메이션**: 정면 기준 **2프레임**(도구를 위로 들어올림 / 아래로 내려찍음).
- **일관성**: 4방향·모든 프레임에서 **동일 인물**(같은 얼굴/의상/색/크기/두께). 캔버스 내 발 위치·중심 정렬 통일.
- (선택) 정지 idle 1프레임, 계급별 의상 배리에이션.

## 6. 몬스터/오브젝트/건물 규격
- **몬스터**: 귀엽지만 종류 구분이 뚜렷하게(슬라임=말랑, 골렘=바위, 드래곤=아기용 등). 보스는 더 크고 위엄.
- **월드 오브젝트**: 나무/낚시터/광맥/밀밭/고물더미/해적선/던전입구/구름 등 — 멀리서도 "무엇을 하는 곳"인지 즉시 파악.
- **건물**(상점/집/기부소/수첩): 작은 단일 건물, 상징 요소(차양/하트/책 좌판 등) 명확. 정면-부감 통일.
- 모두 **동일 광원·바닥 그림자·라운드 감성**으로 나란히 놨을 때 한 세트.

## 7. 아이템/아이콘 규격
- **아이템**: 단일 오브젝트를 정면-살짝 부감으로. 배경 투명. 작은 크기에서 식별되도록 심플·굵게.
- **UI 아이콘**(가방/빠른이동/설명서/설정, HUD 계급·별머니·체력·피로·선행): **동일한 선 두께·모서리 라운드·채도**로 아이콘 세트감. 픽토그램에 가깝게 단순화.

## 8. 파일·명명·연결 규격
- **경로**: `assets/sprites/<종류>/<아이디>.png`
  - 종류: `char`(캐릭터) · `mon`(몬스터/보스) · `item`(자원/전리품/가공품) · `obj`(월드 오브젝트/건물) · `ui`(아이콘) · `bg`(배경/타일, 선택)
- **아이디**: 소문자 스네이크. 캐릭터 `char/down_0`,`char/up_1`,`char/left_0`,`char/work_0`… / 몬스터 `mon/slime` / 아이템 `item/branch` / 오브젝트 `obj/tree`,`obj/b_shop` / 아이콘 `ui/bag`,`ui/hud_star`.
- 정확한 아이디·개수는 `docs/ASSET_CHECKLIST.md`에 정의.
- **연결(참고, 별도 구현 과제)**: 게임은 준비된 이미지를 `js/data/assets.js`의 목록으로 인식해 표시.
  ⚠️ **플레이 링크(아티팩트)는 외부 PNG를 못 불러오므로**, 표시되려면 **빌드시 data URI로 인라인**하는 작업이 필요(현재 미구현, 별도 과제).

## 9. 통일성 체크(Do/Don't)
- ✅ 마스터 스타일 문구+팔레트 고정, 투명 배경, 위쪽 광원, 바닥 타원 그림자, 굵은 실루엣, 파스텔.
- ✅ 새 에셋을 기존 것과 나란히 뒀을 때 이질감 0.
- ❌ 스타일/채도/그림자/두께가 에셋마다 제각각, 사실적 3D/픽셀아트, 배경 불투명, 텍스트·워터마크, 잘림.
