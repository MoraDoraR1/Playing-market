## 플레이어 기본
| 항목 | 값 |
|---|---|
| 시작 체력(HP) | 60 |
| 공격력 | 6 + 무기레벨×4 (+전투 시 0~5 난수) |
| 채집 1회 수확량 | 1 ~ (1+도구레벨) |

| 전투 공격 피로도 | +5 / 회, 승리 시 +12 |

## 집 콘텐츠 (P2)
### 작업대(제작)
| 산출물 | 재료 | 효과 |
|---|---|---|
| 합판 | 나뭇가지×3 | 가공 재료(판매가 45) |
| 튼튼 침대틀 | 합판×3 | 최대체력 +20 |
| 뮤직박스 | 합판×2 + 보석×1 | 생산 피로 -2 |
| 수련 목검대 | 합판×2 + 철광석×2 | 공격력 +4 |
| 책장 | 합판×3 + 약초×2 | 활동 시 내공 +2 |
| 화분 | 합판×1 + 버섯×2 | 꾸미기 전용 |
