# 🛒 키즈짱 시장놀이

아이들이 **물건 담기**와 **돈 계산**을 놀이로 배우는 웹 게임입니다.
설치 없이 `index.html` 파일을 브라우저로 열기만 하면 바로 플레이됩니다!

## 🎮 어떻게 노나요?

1. 위쪽 **장보기 목록**을 확인해요. (예: 사과 2개, 우유 1개)
2. 시장 진열대에서 필요한 물건을 눌러 **장바구니**에 담아요.
3. 목록에 딱 맞게 담았으면 **계산하기 💰** 버튼을 눌러요.
4. 정확히 맞추면 별을 받고 다음 단계로 넘어가요! ⭐

## 🌟 특징

- **단계별 난이도**: 단계가 오를수록 살 물건 종류와 개수가 늘어나요.
- **지갑 개념**: 가진 돈 안에서 계산해야 해요. (돈이 부족하면 안 돼요!)
- **거스름돈 보너스**: 알뜰하게 사면 별을 더 많이 받아요.
- **효과음 & 애니메이션**: 담을 때마다 통통 튀는 재미!
- **모바일 지원**: 휴대폰, 태블릿에서도 잘 돼요.

## 🛠️ 기술

- 순수 HTML / CSS / JavaScript (외부 라이브러리 없음)
- Web Audio API로 효과음 처리
- 단일 파일 구성 → 공유·배포가 쉬워요
