# 🏘️ 키즈짱 시장놀이

추억의 **다음 키즈짱 "시장놀이"(원제 조이월드)** 를 오마주한 웹 게임입니다.
장보기 계산 게임이 아니라, **자원을 모아 팔고 계급을 올리는 생활·경제 시뮬레이션**이에요.
설치 없이 `index.html`을 브라우저로 열면 바로 플레이됩니다!

## 🎮 핵심 게임 루프

1. **채집·낚시·채광·사냥** — 숲🌲 / 바다🌊 / 광산⛏️ / 들판🌾 에서 자원을 모아요.
2. **판매** — 상점🏪에 가서 모은 자원을 팔아 게임머니를 벌어요.
3. **성장** — 번 돈으로 도구를 강화하고, 활동으로 얻은 **내공점수**로 계급을 올려요.
4. **선행** — 기부소❤️에서 돈을 기부해 **선행점수**를 쌓으면 **하늘나라☁️**가 열려요!

## 🌟 원작에서 가져온 시스템

- **피로도** 😴 — 생산 활동을 하면 피로가 쌓이고, 가득 차면 활동 불가. 집🏠에서 자야 회복돼요. (푹신침대를 사면 완전 회복!)
- **계급(신분) 시스템** 🏅 — 내공점수를 모아 **평민 → 견습꾼 → 상인 → 부농 → 대상인 → 귀족 → 백작 → 공작 → 생명의 왕**까지 승급.
- **선행점수 & 하늘나라** ❤️☁️ — 기부로 선행을 쌓으면 특별 장소 하늘나라 개방. 귀한 보물이 가득!
- **레어 아이템** 💎 — 채집 중 낮은 확률로 산삼·진주·보석·황금알 같은 귀한 자원 획득.
- **도구 강화** ⚒️ — 강화할수록 한 번에 얻는 자원 수가 늘어나요.

## 🛠️ 기술

- 순수 HTML / CSS / JavaScript (외부 라이브러리 없음)
- Web Audio API 효과음, 단일 파일 구성 → 공유·배포가 쉬워요
- 모바일 지원

즐겁게 시장을 누비고, 생명의 왕까지 도전해보세요~ 👑
